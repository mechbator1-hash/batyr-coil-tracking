# 1. Цель
Автоматизировать приёмку рулонов металла на складе БАТЫР. Кладовщик выполняет два сканирования — штрихкод рулона и штрихкод ячейки. Все данные о рулоне извлекаются из штрихкода автоматически. Ручного ввода нет вообще.

## 2.3 Определение размера (толщина × ширина)
Размер в штрихкоде ММК не закодирован — только на этикетке текстом. Заявки открываются на большие объёмы по нескольким размерам одновременно, поэтому автоматическое определение по весу ненадёжно — диапазоны весов разных размеров пересекаются.

Правильное решение: система показывает список открытых позиций заявки, кладовщик выбирает одним тапом — сверяясь с этикеткой рулона где размер написан крупным шрифтом.

# 3. Штрихкоды других поставщиков
## 3.1 НЛМК
На этикетке НЛМК есть линейный штрихкод «Идентификационный код» и DataMatrix/QR. Структура отличается от ММК.


До получения расшифровки НЛМК — резервный вариант: логист вносит плавку и вес по УПД за компьютером после приёмки. Кладовщик всё равно только сканирует.

## 3.2 Северсталь
