## 1. Суть проекта

Создание системы учёта стального рулона от момента приёмки на склад до полного расходования на штамповке и сварке. Интеграция: сканер штрихкода → Python → 1С:УТ → Siemens S7 (ПЛК пресса и сварки) → этикетка пачки.

**Проблема сейчас:** рулоны не привязаны к плавке и партии в системе, расход стали не отслеживается в реальном времени, списание ручное и неточное.

**Результат проекта:** каждая бочка прослеживается до плавки стали; расход рулона списывается автоматически по счётчику пресса; склад рулонов ведётся в 1С без ручного ввода.

---

## 2. Scope проекта

### Входит
- Приёмка рулонов ММК (штрихкод Code128) → карточка в 1С:УТ
- Адресное хранение рулонов (ячейки склада)
- Передача рулона в производство (сканирование ячейки)
- Автосписание обечаек по счётчику пресса (Siemens S7)
- Автосписание по счётчику сварки (Siemens S7)
- Печать этикетки пачки (TSC DA220W, формат BATYR-ГГММДД-партия-№)
- Выбор размера рулона из списка открытых позиций заявки (не по весу)
- Обработка исключений: брак, стык рулонов, остаток пачки, перезапуск ПЛК

### Не входит (следующий этап)
- Интеграция с НЛМК и Северсталью (структура штрихкода не изучена)
- Учёт крышек и дна (отдельная линия)
- Мобильное приложение для кладовщика (пока — стационарный ПК/планшет)
- Автоматическая выгрузка в бухгалтерию

## 6. Ключевые технические решения (зафиксированы)

| Вопрос | Решение |
|--------|---------|
| Определение размера рулона | Список открытых позиций заявки → кладовщик тапает (не по весу — диапазоны пересекаются) |
| Связь с ПЛК | python-snap7 (S7-1200/1500) или OPC Kepware (S7-300) — уточнить после обследования |
| Принтер этикеток | TSC DA220W, ZPL по WiFi |
| Формат этикетки пачки | BATYR-ГГММДД-[партия]-[порядковый] |
| Универсальный сканер | Тип объекта определяется по структуре строки: ММК-рулон / пачка БАТЫР / ячейка склада |
| Поставщики стали | ММК — разобрана структура штрихкода. НЛМК, Северсталь — заглушка, нужно сканировать |

## 7. Риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| ПЛК без Ethernet или без нужных регистров | Средняя | Высокое | Обследование до начала разработки |
| Нет WiFi в зоне приёмки | Низкая | Среднее | Проверить заранее, протянуть точку доступа |
| 1С-разработчик не знает HTTP REST | Средняя | Высокое | Техническое интервью при выборе |
| Кладовщик не принимает новый процесс | Низкая | Среднее | Пилот с одним сотрудником, 2 сканирования + 1 тап |
| Штрихкод НЛМК/Северсталь нечитаем стандартным сканером | Низкая | Среднее | DataMatrix — нужен 2D-сканер (Zebra DS2208 поддерживает) |
