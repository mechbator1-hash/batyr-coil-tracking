## Штрихкод ММК — структура (28 символов, Code128)

| Позиции | Длина | Содержание |
|---------|-------|------------|
| 1–3 | 3 | Код цеха-отправителя |
| 4–5 | 2 | Год (последние 2 цифры) |
| 6–11 | 6 | Плавка (номер плавки) |
| 12–18 | 7 | Партия (номер партии) |
| 19–23 | 5 | Номер рулона |
| 24–28 | 5 | Вес нетто (кг, целые) |

Пример: `12324А1234Б1234567001057850` → цех 123, год 24, плавка А1234Б, партия 1234567, рулон 00105, вес 7850 кг.

**НЛМК и Северсталь** — структура неизвестна, нужно сканировать на ближайшей поставке и зафиксировать.

## Ключевое архитектурное решение

### Определение размера рулона (v4.0 — исправление критической ошибки)

**Проблема v3.0:** Автоопределение размера по весу — ненадёжно. Заявки открываются на большие объёмы по нескольким размерам одновременно (например, `0,74×910 — 1200т`, `0,83×1218 — 1500т`, `0,83×905 — 400т`), диапазоны весов пересекаются.

**Решение v4.0:** Система показывает список открытых позиций заявки, кладовщик смотрит на физическую этикетку рулона (размер написан крупно: `0.830*905`) и тапает нужную строку — 1 действие.

```
Выбери размер рулона:
┌─────────────────────────────────────┐
│  0,74 × 910    остаток 847 т        │
│  0,83 × 1218   остаток 1 312 т      │
│  0,83 × 905    остаток 400 т        │
└─────────────────────────────────────┘
```

**Итог: 2 сканирования + 1 тап. Ввод вручную = 0.**

## Архитектура системы

```
ММК штрихкод (сканер) 
    ↓
Python-скрипт (парсинг, REST API)
    ↓
1С:УТ HTTP-сервис
    ↓ (карточка рулона с плавкой, партией, весом, размером, ячейкой)
Siemens S7 PLC (счётчик ходов пресса / циклов сварки)
    ↓ (Python читает через python-snap7 / OPC Kepware)
1С:УТ — списание со склада пачки, формирование партии бочек
    ↓
Этикетка пачки (TSC DA220W, ZPL по WiFi)
    BATYR-ГГММДД-[партия]-[порядковый]
```

### Оборудование

| Компонент | Модель/Протокол |
|-----------|-----------------|
| Сканер штрихкодов | Honeywell Voyager (кабель) или Zebra DS2208 |
| Принтер этикеток | TSC DA220W (ZPL, WiFi) |
| ПЛК (уточнить!) | Siemens S7-1200/1500 → python-snap7 |
| ПЛК (уточнить!) | Siemens S7-300 → OPC Kepware |
| БД | 1С:УТ 11, HTTP REST сервис |
| Ячейки склада | Бумажные этикетки с штрихкодом Code128 |

### Универсальный алгоритм сканирования

По структуре числа система сама определяет тип объекта:
- 28 символов (цифры+буквы) → ММК рулон
- Начинается с `БАТЫР-` / `BATYR-` → пачка бочек
- Короткий код (4–8 символов) → ячейка склада
- Другая структура → НЛМК / Северсталь (нужно добавить после изучения)
