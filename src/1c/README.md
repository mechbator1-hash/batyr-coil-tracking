# 1С:УТ — конфигурация и HTTP-сервис

## Планируемые объекты

- HTTP-сервис `КоилТрекинг` — приём данных от Python
- Справочник `РулоныСтали` — карточка рулона (плавка, партия, размер, вес, ячейка)
- Документ `ПриходРулона` — оприходование при приёмке
- Документ `ПередачаВПроизводство` — списание с адресного склада
- Документ `ЭтикеткаПачки` — формирование партии бочек
- Регистр накопления `ОстаткиРулонов` — оперативный учёт по ячейкам
