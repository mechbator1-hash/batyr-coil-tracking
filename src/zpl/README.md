# ZPL — шаблоны этикеток

Принтер: TSC DA220W, подключение по WiFi (порт 9100).

## Формат этикетки пачки

```
BATYR-ГГММДД-[партия]-[порядковый]
```

Пример: `BATYR-261101-П00123-001`

Файлы:
- `pacha_label.zpl` — основной шаблон этикетки пачки бочек
- `cell_label.zpl` — этикетка ячейки склада рулонов
