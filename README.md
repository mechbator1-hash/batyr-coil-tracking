# БАТЫР — Автоматизация учёта стального рулона

Система учёта стального рулона от приёмки до полного расходования на штамповке и сварке.

## Стек
- **Siemens S7** (S7-1200/1500 или S7-300) — счётчики пресса и сварки
- **Python** — парсинг штрихкода, REST-клиент 1С, чтение ПЛК
- **1С:УТ 11** — карточка рулона, адресный склад, партии бочек
- **TSC DA220W** — печать этикеток пачки (ZPL по WiFi)

## Структура репозитория

```
docs/          — паспорт проекта, ТЗ, архитектурные решения
src/python/    — модуль парсинга штрихкода, Siemens, REST-клиент 1С
src/1c/        — HTTP-сервис 1С, описание конфигурации
src/zpl/       — шаблоны этикеток TSC DA220W
tests/         — тесты парсера и бизнес-логики
```
